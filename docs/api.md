# REST API

Базовый адрес: `/api/` (локально `http://127.0.0.1:8000/api/`, на Render `https://spoibd-pz5.onrender.com/api/`). Маршруты подключены через `DefaultRouter` в `accounts/urls.py`, обработчики — в `accounts/views.py`.

## Общие правила

- **Аутентификация:** сессия Django. Сначала выполняется вход через `/accounts/login/`, затем браузер передаёт cookie сессии с каждым запросом. Без входа любой маршрут API отвечает `403 {"detail": "Authentication credentials were not provided."}`.
- **CSRF:** запросы POST, PUT, PATCH, DELETE должны содержать заголовок `X-CSRFToken`. Страницы сайта передают его автоматически (`accounts/static/accounts/api.js`).
- **Формат:** тело запроса и ответа — JSON (`Content-Type: application/json`).
- **Роли:** «методист» — пользователь в группе «Методист», остальные пользователи — студенты.
- **Проверка из браузера:** при открытии адреса API в браузере после входа DRF показывает страницу с ответом и формой отправки запросов (вкладка Raw data, кнопки POST / PUT / PATCH / DELETE).

| Код | Когда возвращается |
|---|---|
| 200 OK | успешное чтение или изменение |
| 201 Created | объект создан |
| 204 No Content | объект удалён |
| 400 Bad Request | ошибка данных или бизнес-правила; в ответе JSON с полем и текстом ошибки |
| 403 Forbidden | не выполнен вход или у роли нет права на действие |
| 404 Not Found | объекта нет или он чужой для текущего пользователя |
| 405 Method Not Allowed | метод не поддерживается маршрутом (например, GET на `/issue/`) |
| 500 | сбой сервера; интерфейс показывает «Сервис временно недоступен» |

| PATCH, PUT | `/api/enrollments/{id}/` | изменить статус заявки на курс | методист |

| POST | `/api/loans/{id}/return/` | принять возврат | методист |

## Курсы

### GET /api/courses/

| Параметр | Значение |
|---|---|
| Назначение | список курсов для выпадающих списков и фильтров |
| Аутентификация | сессия |
| Тело запроса | нет |
| Успех | `200`, массив курсов |
| Ошибки | `403` — не выполнен вход |

```json
[{"id": 1, "title": "Базы данных", "description": "", "department": 1, "max_students": 30}]
```

Создание, изменение и удаление курса (`POST /api/courses/`, `PATCH/PUT/DELETE /api/courses/{id}/`) доступны только методисту, студент получает `403`. Курс, на который есть заявки или учебники, удалить нельзя (`PROTECT`): сервер отвечает ошибкой `500` (ProtectedError), данные не меняются. Такие курсы удаляются через `/admin/` после удаления связанных записей.

## Заявки на курсы (ПЗ №7)

### POST /api/enrollments/

| Параметр | Значение |
|---|---|
| Назначение | студент подаёт заявку на курс; автором сервер записывает текущего пользователя |
| Аутентификация | сессия + CSRF |
| Тело запроса | `{"course": 1}` |
| Успех | `201`, созданная заявка со статусом `pending` |
| Ошибки | `400 {"course": ["Вы уже подали заявку на этот курс."]}`; `400` — попытка сразу передать статус, отличный от `pending` |

```json
{"id": 1, "course": 1, "course_title": "Базы данных", "student": 30, "student_name": "Student", "status": "pending", "created_at": "2026-10-25T14:30:19.198368Z"}
```

### PATCH /api/enrollments/{id}/

| Параметр | Значение |
|---|---|
| Назначение | методист зачисляет студента или отклоняет заявку |
| Аутентификация | сессия + CSRF, роль «Методист» |
| Тело запроса | `{"status": "approved"}` или `{"status": "rejected"}` |
| Успех | `200`, обновлённая заявка |
| Ошибки | `400 {"status": ["Недопустимый переход статуса."]}` — заявка уже рассмотрена; `400 {"status": ["На курсе не осталось свободных мест."]}`; `403` — запрос от студента; `404` — заявка не найдена |

`GET /api/enrollments/` и `GET /api/enrollments/{id}/` возвращают заявки в том же формате; `DELETE /api/enrollments/{id}/` удаляет заявку и отвечает `204`.

## Учебники

### GET /api/books/

| Параметр | Значение |
|---|---|
| Назначение | список учебников с числом свободных экземпляров. Учебники добавляются через `/admin/` или командой `seed_library`; через API их можно только читать |
| Аутентификация | сессия |
| Успех | `200` |
| Ошибки | `403` — не выполнен вход; `405` — попытка POST/PATCH/DELETE |

```json
[{"id": 1, "title": "Учебник по курсу «Базы данных»", "author": "", "course": 1, "course_title": "Базы данных", "total_copies": 2, "available_copies": 2}]
```

## Заявки на учебники (СРС №7)

Статусы: `requested` — заявка создана, `issued` — учебник выдан, `returned` — учебник возвращён, `cancelled` — заявка отменена.

| Текущий статус | Действие | Новый статус |
|---|---|---|
| `requested` | `issue` | `issued` (свободных экземпляров −1) |
| `requested` | `cancel` | `cancelled` |
| `issued` | `return` | `returned` (свободных экземпляров +1) |
| любой другой случай | — | `400`, ничего не меняется |

### GET /api/loans/

| Параметр | Значение |
|---|---|
| Назначение | список заявок на учебники: методисту — все, студенту — только свои |
| Аутентификация | сессия |
| Параметры URL | `status` — один из статусов; `course` — id курса. Оба необязательны и могут использоваться вместе: `/api/loans/?status=issued&course=3` |
| Успех | `200`, массив заявок, новые сверху |
| Ошибки | `400 {"status": "Неизвестный статус в фильтре."}`; `400 {"course": "Параметр course должен быть числом."}`; `403` — не выполнен вход |

### POST /api/loans/

| Параметр | Значение |
|---|---|
| Назначение | создать заявку на учебник. Читателем сервер записывает текущего пользователя, статус всегда `requested`, в историю записывается событие `created` |
| Аутентификация | сессия + CSRF |
| Тело запроса | `{"book": 3, "comment": "к экзамену"}` (`comment` необязателен, до 255 символов) |
| Успех | `201` |
| Ошибки | `400 {"book": ["У вас уже есть активная заявка на этот учебник."]}`; `400 {"status": [...]}` — в теле передан статус |
| Проверка | в Network виден `POST /api/loans/` → 201; запись видна в `/admin/accounts/bookloan/`, событие — в `/admin/accounts/loanevent/` |

```json
{"id": 3, "book": 3, "book_title": "Учебник по курсу «Теория инноваций»", "course_title": "Теория инноваций", "reader": 30, "reader_name": "Student", "status": "requested", "status_display": "Заявка создана", "comment": "к экзамену", "created_at": "2026-10-25T14:30:19.154680Z"}
```

### GET /api/loans/{id}/

Возвращает одну заявку в формате выше. Ошибки: `404` — заявки нет или она принадлежит другому студенту.

### PATCH /api/loans/{id}/

| Параметр | Значение |
|---|---|
| Назначение | автор меняет комментарий или учебник в заявке, пока она в статусе `requested`; в историю записывается событие `updated`. `PUT` работает так же, но требует передать `book` |
| Аутентификация | сессия + CSRF, только автор заявки |
| Тело запроса | `{"comment": "к сессии"}` |
| Успех | `200`, обновлённая заявка |
| Ошибки | `400 {"status": ["Статус меняется только действиями issue, return и cancel."]}` — в теле передан `status`; `400 {"status": "Изменять можно только заявку в статусе «Заявка создана»."}`; `403` — запрос от методиста; `404` — чужая заявка |

### DELETE /api/loans/{id}/

| Параметр | Значение |
|---|---|
| Назначение | удалить заявку в статусе `requested` или `cancelled` вместе с её историей. Интерфейс сначала запрашивает подтверждение |
| Аутентификация | сессия + CSRF, автор или методист |
| Успех | `204`, тела ответа нет |
| Ошибки | `400 {"status": "Удалить можно только новую или отменённую заявку."}`; `404` |

### POST /api/loans/{id}/issue/

| Параметр | Значение |
|---|---|
| Назначение | выдать учебник. В одной транзакции: свободных экземпляров −1, статус `issued`, событие `issued` в истории |
| Аутентификация | сессия + CSRF, роль «Методист» |
| Тело запроса | нет |
| Успех | `200`, заявка со статусом `issued` |
| Ошибки | `400 {"status": ["Недопустимый переход: заявка в статусе «Возвращён»."]}`; `400 {"book": ["Нет свободных экземпляров этого учебника."]}`; `403` — запрос от студента; `404` |
| Проверка | в Network `POST .../issue/` → 200, затем в `GET /api/books/` у учебника уменьшилось `available_copies` |

### POST /api/loans/{id}/return/

Принять возврат: статус `issued` → `returned`, свободных экземпляров +1, событие `returned`. Роль «Методист». Ошибки: `400` — заявка не в статусе `issued`; `403`; `404`.

### POST /api/loans/{id}/cancel/

Отменить заявку: `requested` → `cancelled`, событие `cancelled`. Может автор или методист. Ошибки: `400 {"status": ["Недопустимый переход: заявка в статусе «Выдан»."]}` — выданный учебник нужно сначала вернуть; `404`.

### GET /api/loans/{id}/history/

| Параметр | Значение |
|---|---|
| Назначение | история событий заявки в порядке возникновения |
| Аутентификация | сессия, автор или методист |
| Успех | `200` |
| Ошибки | `404` |

```json
[
  {"id": 5, "action": "created", "action_display": "Заявка создана", "old_status": "", "new_status": "requested", "actor_name": "Student", "created_at": "2026-10-25T14:30:19.155081Z"},
  {"id": 7, "action": "issued", "action_display": "Учебник выдан", "old_status": "requested", "new_status": "issued", "actor_name": "methodist", "created_at": "2026-10-25T14:30:19.172929Z"}
]
```

## Проверка доступности

### GET /healthz/

Обычное представление Django без DRF и без входа. Ответ `200 {"status": "ok"}` означает, что Django запущен и обрабатывает запросы. К базе данных этот адрес не обращается; связь с базой подтверждает, например, `GET /api/loans/`, который возвращает ранее созданные записи.
